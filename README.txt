ADD YOUR PHOTO / SCREENSHOTS LATER
You do not need to upload any images now. When ready:
1. Add the image file to the assets folder.
2. In index.html, find the matching placeholder and its comment.
3. Replace the placeholder div with an image tag. Example:
   <img src="assets/zak-garments.jpg" alt="ZAK Garments social media campaign">
4. Keep descriptive alt text for accessibility and image SEO.

Suggested image filenames:
- arisha-photo.jpg
- zak-garments.jpg
- maka-matcha.jpg
- wajeeh-zeeshan.jpg
- club-21.jpg

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new PUBLIC repository, e.g. arisha-portfolio.
2. Upload index.html, styles.css, script.js, README.txt and the assets folder.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for deployment. Your link will look like:
   https://YOUR-GITHUB-USERNAME.github.io/arisha-portfolio/
7. Open the live link on desktop and phone before submitting.
